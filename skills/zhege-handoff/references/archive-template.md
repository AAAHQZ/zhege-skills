# 会话存档文档模板

存档文档的唯一目的：**下一个会话（或一个月后的自己）能在 30 秒内接上上下文**。
所以结构固定、章节标题固定，不要即兴发挥。

落盘路径：`<workspace>/docs/session-archives/session-<session_id 后 8 位>-<YYYYMMDD-HHMM>.md`

## 写作规则

1. **结论前置。** 每节第一句就是结论，展开放后面。
2. **只引用不复制。** 代码、spec、commit 已有内容一律给 `路径:行号` 或短 sha。抄一遍 = 两份会漂移的真相。
3. **脱敏。** 出现以下内容立即替换成 `***REDACTED***`：API key / token / 密码 / 私钥 / cookie / 身份证 / 手机号 / 内网 host+port。存档会进 git，泄漏成本很高。
4. **写人话。** 这是给未来的 agent 看的，不是给评审看的。不用铺垫、不用"本次会话我们主要做了……"。
5. **元信息里的"未提交文件数"用 `git status --short | Measure-Object -Line` 拿**，顺便记下有哪些（`git status --short`），因为未提交的东西往往是下个会话的入口。
6. **时间是本地时间 +08:00**，`session messages` 返回的 `timestamp` 是毫秒 epoch，需要自己换算。
7. 存档本身**不自动 git add / commit**。落盘后提醒用户一句"要不要提交"，由用户决定。
